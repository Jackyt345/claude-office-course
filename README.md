# Claude 辦公室實戰互動課

給書籍出版公司主管、特別助理與不動產仲介公司秘書的 Claude 實戰課程網站。

- 課程講義：七個模組，含操作示意圖
- 對話練習：核心 10 題，之後接延伸題庫 36 題，講師講解後立即作答，附詳解與各選項分析
- 模擬測驗：核心 10 題（20 分鐘）與延伸題庫 36 題（60 分鐘）兩種，題號盤、標記、交卷後逐題檢討

講師：唐晨峰（國立陽明交通大學公共衛生研究所博士生、臺北醫學大學醫療暨生物科技法律研究所碩士生）
